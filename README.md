# Shopify Storefront Development — Teuta Matoshi

Selected custom Shopify development from the production Teuta Matoshi storefront.

**Live site:** https://www.teutamatoshi.com/

## Project scope

I rebuilt and customized the storefront on Shopify using the Baseline theme as the commercial foundation, then developed custom sections, storefront interactions, product/sizing flows, navigation, filtering, responsive behavior, and supporting e-commerce UI.

A comparison against a clean Baseline 5.4.0 export showed:

- 27 added files
- 69 modified files
- 246 unchanged files

## Technologies

Shopify Liquid · JavaScript · CSS · HTML · Metafields · Shopify Theme Architecture

## Portfolio code in this repository

This repository contains selected custom files created for the storefront, including custom homepage sections, image-switching interactions, navigation helpers, product review components, and storefront UI behavior.

The complete production theme is intentionally **not** published here. Baseline is a commercial Shopify theme, so its original source and modified vendor/theme files are excluded. Store configuration, customer data, credentials, and private business logic are also excluded.

## Selected work

- Custom Shopify homepage sections and responsive layouts
- Custom JavaScript storefront interactions
- Product and sizing workflow development
- Search, filtering, navigation, and collection UX improvements
- Reusable Liquid snippets and theme components
- Responsive storefront behavior across desktop and mobile

> Portfolio excerpt only. This repository is intended to demonstrate development work and does not redistribute the underlying commercial Baseline theme.
